# Foundation of Group Theory

## 1. Set

Suppose $\mathrm N$ refers to nature numbers set. And $\mathrm J_n = \{1,2,3,...n \}$. 

Definition 1.1: 
Suppose S is a set. S is finite iff $\exists n\in \mathrm N$ such that  $ \exists f:\mathrm J_n \rightarrow \mathrm S$，$f$ is a bijection. 
$n$ is called the cardinality of $S$, denoted by $\mathrm{Card}\{S\}$.

Proposition 1.2: 
Suppose $S$ is a finite set and $f:S\rightarrow S$.
$f$ is a surjeciton $\longleftrightarrow$ $f$ is a injeciton$\longleftrightarrow$ $f$ is a bijeciton

Proposition 1.3: 
Suppose $A$ and $B$ are both infinite sets. If $\mathrm{Card} \{A\} > \mathrm{Card} \{B\}$，then there's no injection from $A$ to $B$.

Proposition 1.4: 
Suppose $A$ and $B$ are both sets while $A$ is infinite and $B$ is finite. then there's no injection from $A$ to $B$​.

## 2. Groupoid

A groupoid is a nonempty set with a binary operation.

Definition 2.1:
Suppose $G$ is a nonempty set and $f:G\times G\rightarrow G$. 
$\forall a,b\in G$, $f(a,b)$ is denoted as $a*b$.
$G$ with $*$ defined on it, denoted by $(G*)$, is called a groupoid.

Two groupoid is called 'isomorphism' if they have the same structure under their corresponding binary operations.

Definition 2.2:
Suppose $(G_1,*)$ and $(G_2,\cdot)$ are two groupoids. $f:G_1\rightarrow G_2$
$\forall a,b\in G_1, \  \ f(a*b) = f(a)\cdot f(b)\Longleftrightarrow $ $f$  is a homomorphism from $G_1$ to $G_2$.

Definition 2.3:
Suppose $(G_1,*)$ and $(G_2,\cdot)$ are two groupoids. 
$\exists f$, $f$  is a homomorphism bijection from $G_1$ to $G_2$ $\Longleftrightarrow$ $G_1$ and $G_2$ are isomorphism.

## 3. Semigroup

A semigroup is a groupoid whose related operation satisfies associativity.

**Definition 3.1:**
Suppose $(S,*)$​ is a groupoid.
$\forall a,b,c\in S,\ \ a*b*c = a*(b*c)$ $\Longleftrightarrow$ $S$​​​ is a semigroup. 

A classic example of a groupoid without associativity is $(N, *)  \ \ \forall n,m \in N, \ \ n*m = n^m$.
In $(N,*)$ if you applied the operation on one element repeatedly, you cannot yield unique result as it's decided by the input order you choose. For example, suppose $a$ is an arbitrary element of $N$.

$a*\underbrace {a*a...*a}_{n\  \ a} = a^{a^n}\neq a^{an} = \underbrace {a*a...*a}_{n\  \ a}*a $

Hence, power operation cannot be defined on a groupoid without associativity.

In semigroup, situation changes.

Suppose $(S,*)$ is a semigroup Trivially, $S$ is close under $*$. For any $a\in S$, $a*a\in S$. Image that: what would happen if we repeatedly apply $*a$ to $a*a$?

After $n$ times, we can get $a^n = \underbrace{a*a*...a}_{n \ \ a}$. By associativity, $a^n$ is well-defined.

Let $P$ denote $P:S\times N\rightarrow S$, $\forall a\in S, n\in n, \ \ P(a,n):=a^n$.
$P_n$ denote $P_n:S\rightarrow S, \forall a \in G, P_n(a):=a^n$
$P_a$ denote $P_a:N\rightarrow S,\forall n\in N, P_a(n):=a^n$​

**?????** What is the property of $P_n$​ ?

Clearly, for some $a\in G$ and $n\in N$, $P_a$, $P_n$ is a function on $G$​. If $P_n$ is a surjection, then all elements in $G$ can be yielded by $a$ multiples itself for proper times. In this case, we called $G$​ a cyclic group.

**Definition 3.2:**
Suppose $(G,*)$ is a group. $(G,*)$ is **cyclic** iff $P_a$ is a surjection.
Otherwise, $(G,*)$ is cyclic iff $\exists a\in G, \forall b\in G, \ \ \exists n \in N, a^n = b$. 

## 4. Group

**Definition 4.1:**

Suppose $S$ is a set and $*$ is an operation on $S$. $S$ is a group iff

1. Associativity: $\forall a,b,c \in S,  \ \ (a*b)*c = a*(b*c)$
2. With identity: $\exists e \in S,\ \  \forall a\in S \ a*e = e*a = a$
3. Inversible: $\forall a \in S, \exists b\in S,\  \ a*b = e$

Obviously, integer numbers set with normal addition and Rational number with normal multiplication are groups. 

Definition above best describes the properties of a group. However, it's not the simplest one:

**Definition 4.2:**

Suppose $S$ is a set and $*$ is an operation on $S$. $S$ is a group iff

1. Associativity: $\forall a,b,c \in S,  \ \ (a*b)*c = a*(b*c)$
2. With left identity: $\exists e \in S,\ \  \forall a\in S \ a*e = e*a = a$
3. Left inversible: $\forall a \in S, \exists b\in S,\  \ a*b = e$​

With associativity, we can induce 'with right identity' and 'right inversible'.

Besides adding these two properties, there's another way **for a semigroup to become group**:

**Theorem 4.3:**
Suppose $(S,*)$ is a semigruop. $(S,*)$ is a group iff:

1. $\forall a,b\in S, \ \ \exists x \in S, \ \ a*x = b$
2. $\forall a,b\in S, \ \ \exists y \in S, \ \ y*a = b$

Proof: ……

Proposition above indicates that: for a element $a$ in $S$,  $f:S\rightarrow S \ \, f(x):=a*x$ , denoted as $f_a$, called the left translation of $S$ for $a$, is surjective. Hence, if $S$ is a finite set, by **1.2**,  it's injective (therefore bijective):

**Theorem 4.4:**
Suppose $(G,*)$ is a group. If $G$ is finite, then $(G,*)$ is cancellable.
Otherwise, finite groups are cancellable.

With group's definition and its equivalence known, we can now examine the injectivity of $P_a$ with knowledge of inverse.

Obviously, if $P_a$ is injective, $P_a(N)$​ is an infinite set.

**Theorem 4.5:**
Suppose $(G,*)$ is a group and $a\in G$.
$P_a$ is injective $\longleftrightarrow $ $P_a(N)$ is infinite.

Proof：
We prove the equivalence of these two proposition by examining their contrapositive.
Otherwise, we prove :
$P_a$ is not injective $\longleftrightarrow $ $P_a(N)$ is finite.

$(\longrightarrow)$

$\exists k_1,k_2 \in N, (n\neq m) \and (a^{k_1} = a^{k_2})$. 
Without loss of generality, we assume $k_1< k_2 $. Then, by multiple $a^{-1}$ for $k_1$ times on both sides, we have $e = a^{k_2-k_1}$.

Therefore, $a^n$ go back to $e$ after $k_2-k_1$ times' loop. Now we prove the value of $P_a$ loops in $S = \{e, a,a^2,a^3...a^{k_2-k_1-1}\}$

Let $n$ to be an arbitrary natural number. 
If $n\leq k_2-k_1-1$, obviously, $a^n \in S$.
If $n> k_2-k_1-1$, according to the property of natural number, $\exists x\in N,(y\in N\and y<k_2-k_1-1),\ \ n = x(k_2-k_1-1)+y$. 

$a^n  = a^y\in S$. $S$ is the image of $P_a$. 

Obviously, $S$ is finite and $\mathrm{Card}(S) = k_2-k_1$

Q.E.D.

$(\longleftarrow)$

If $P_a$ is finite, by 1.4 there's no injection from an infinite set to a finite set, $P_a$ is not injective.

Q.E.D.

**Proposition 4.6:**
Suppose $(G,*)$ is a group and $a\in G$.
$e\in P_a(N)\longleftrightarrow a^{-1}\in P_a(N) \longleftrightarrow P_a$ is not injective.

In a word, $P_a$ is surjective iff $G$ is a cyclic group. 
$P_a$ is injective iff the image of $P_a$ is infinite. If not, as $n$ getting larger and larger, $a^n$ repeats.

We said $a$ has finite order iff $P_a$ is not injective. Otherwise, $a$ has finite order iff $\exist n\in N, a^n = e$.
If not, $a$ has infinite order.

**Definition 4.7:**
Suppose $(G,*)$ is a group and $a\in G$. 
$(G,*)$ is a periodic group iff every element of $(G,*)$ has finite order.
$(G,*)$ is an untwisted group iff every element of $(G,*)$ has infinite order.
$(G,*)$ is a mixed group iff a element of $(G,*)$​ may have finite or infinite order.

**Proposition 4.8:**
A finite group is periodic.

Proof:
Suppose $(G,*)$ is a finite group.
$\forall a\in G$, $P_a(N)\subseteq G$ is finite. By **4.6**, $P_a$ is not injective, $a$ has finite order.
Hence, $(G,*)$​ is periodic.

## 5. Subgroup

Obviously, subgroups of $(G,*)$  are elements of $G$'s power set, denoted by $\mathscr{P}(G)$. Let $A\cdot B:= \ \ \{ a*b\ \ |\ \ a \in A, b\in B\}$. $A^{-1}:=\{a^{-1} \ \ |\ \ a\in A\}$
$(\mathscr P(G),\cdot)$ is a semigroup with identity $\{e\}$ but not a group. 
Associativity is clear and obviously, it has no inverse for every element.

It's nature to wonder whether we can yield another group by one group or what would happen if we separate a group into two subsets, in what condition they're still group?

Now we give the original definition of subgroup.

**Definition 5.1:**

Suppose $(G,*)$ is a group. $e$ is $G$'s identity. $\forall x \in H$. $x^{-1}$ refers to $x$'s inverse element under $*$.
 $H\subseteq G \and H\neq \empty$. $(H,*)$ is a group iff:

1. $\forall x,y \in H, xy\in H$

2. $\forall x \in H, x^{-1}\in H$​ 

3. $e\in H$   

   (Attention! 3 can be induced by 1 and 2 )

$(H,*)$ is called a subgroup of $(G,*)$​​​.

Otherwise, 
$(H,*)$ is a subgroup of $(G,*)$ $\Longleftrightarrow$ for $(\mathscr P(G),\cdot)$, $(H\cdot H = H)\and (H^{-1} = H)$

Subgroups except for $\{e\}$ and $G$ itself are called **'nontrivial subgroups'** of $G$.

**Theorem 5.2:**
Suppose $(G,*)$ is a group and $e$ is $G$'s identity. $H\subseteq G$
$(H,*)$ is a subgroup of $(G,*)$ $\longrightarrow$ $e\in H$.



We first examine segmentation of $G$ by answering 'besides the original definition of subgroup, what kind of subset of $G$ is a subgroup'.

**Theorem 5.3:**
Suppose $(G,*)$ is a group. $e$ is $G$'s identity. $\forall x \in H$. $x^{-1}$ refers to $x$'s inverse element under $*$.$H\subseteq G \and H\neq \empty$. 

$(H,*)$ is a subgroup of $(G,*)$ iff $\forall a,b \in H, a*b^{-1}\in H$.

Otherwise, $(H,*)$ is a subgroup of $(G,*)$ iff for $(\mathscr P(G),\cdot)$$H\cdot H^{-1} = H$​​

Proof:

($\longrightarrow$) 

$(H,*)$ is a subgroup,  $b\in H\rightarrow b^{-1}\in H$

Hence, $\forall a,b \in H$, $(a\in H\and b\in H) \rightarrow (a*b^{-1}\in H)$.

($\longleftarrow$) 

$H$ is not empty. $\exists a \in H, a*a^{-1} = e$. Hence $e\in H$.

$\forall a (a\in H)\rightarrow  (e*a^{-1} \in H)\rightarrow (a^{-1}\in H)$

$\forall a,b \ \ (a\in H)\and (b\in H) \rightarrow (a\in H)\and (b^{-1}\in H)\rightarrow \\ a*(b^{-1})^{-1}\in H\rightarrow a*b \in H$

Therefore, $(H,*)$ is a subgroup subgroup of $(G,*)$.

Examples before has shown finiteness can bring strong condition. The case of subgroup is no exception.

**Theorem 5.4:**
Suppose $(G,*)$ is a group and $H$ is a finite subset of $G$.
$(H,*)$ is a group iff $H$ is closed under $*$.

Proof:
$(\longrightarrow)$ is clear. 

$(\longleftarrow)$
Assume $(H,*)$ is not a group. 
By 2.1.3, $\exists a\in H, \exists b\in H, \forall x\in H, a*x\neq b$

Hence, $(a^{-1}*b\in G) \and (a^{-1}*b\notin H)$. Hence, $(a^{-1}\notin H)\ \ \or \ \ (b\notin H)$

If $a^{-1}\notin H$, by 4.6, $P_a$ is injective. By 4.5, $P_a(N)$ is infinite.
As $H$ is closed under $*$. $P_a(N)\subseteq H$. $H$ is infinite, contradictory to hypothesis.

If $b\notin H$, contradictory.

Hence, assumption doesn't hold. $(H,*)$​ is a subgroup of $(G,*)$​.

More property of subgroup

Next, we try to figure out the properties of combination of subgroups of $G$​​.



**Theorem 5.5**
Suppose $(G,*)$ is a group. $S(G)$ is the set consists of all subsets becoming subgroup of $(G,*)$ under $*$.
$A,B\in S(A)$ $\longrightarrow$ $A\cap B \in S(A)$.

Otherwise, intersection of  two subgroups is a subgroup.

**Theorem 5.6**
Suppose $(G,*)$ is a group.$S(G)$ is the set consists of all subsets becoming subgroup of $(G,*)$ under $*$.
$(\ \ A,B\in S(A) \ \ ) \and (A\cdot B\in S(A))\longrightarrow A\cdot B = B\cdot A$

Proof:
For $(\mathscr P(G),\cdot)$, $(A\cdot B)^{-1} = B^{-1}\cdot A^{-1}$.
By 5.1, $B^{-1} = B, A^{-1} = A$. Hence, $B^{-1}\cdot A^{-1} = B\cdot A$.
As $(A\cdot B\in S(A)$, by 5.1, $(A\cdot B)^{-1}  = A\cdot B$.
Hence, $A\cdot B = B\cdot A$



**Theorem 5.7**
Suppose $(G,*)$ is a group.$S(G)$ is the set consists of all subsets becoming subgroup of $(G,*)$ under $*$.
$(\ \ A,B\in S(A) \ \ ) \and (A\neq G)\and (B\neq G)$  $\longrightarrow$ $G\neq A\cup B$.
Otherwise, a group cannot be the union of two nontrivial subgroup.

Proof:
Suppose $(\ \ A,B\in S(A) \ \ ) \and (A\subset G)\and (B\subset G)$ and assume $G=  A\cup B$.

Let $x\in G\backslash A, \ \ y\in G\backslash B$, as $G = A\cup B$, $x\in B,\ \ y\in A$.
$A,B\in S(A)$, $x^{-1}\in B, \  \ y^{-1}\in A$.

$x*y \in G = A\cup B$.
If $x*y\in A$, by closure, $(x*y)*y^{-1}  = x\in A$, contradictory.
If $x*y\in B$, by closure, $x^{-1}*(x*y)  = x\in A$, contradictory.
Assumption doesn't hold. $G\neq A\cup B$.
